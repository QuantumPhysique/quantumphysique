# Changelog

All notable changes to quantumphysique, written for the developers of the
apps that use it. Entries are grouped under Breaking, Added, Changed and
Fixed, and every breaking change says what an app has to change.

The package follows [Semantic Versioning](https://semver.org/). Before 1.0, a
breaking change bumps the minor version and everything else the patch.
